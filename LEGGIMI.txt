ZONE DMX (grafica Flight case) - file per GitHub, app privata e offline
=====================================================================

File da caricare su GitHub (stesso nome = sostituiscono quelli vecchi):
- index.html            l'app aggiornata (indirizzi, zone, cablaggi, cabina, PDF)
- sw.js                 la fa funzionare offline (versione v3)
- manifest.webmanifest  nome, colori e icona dell'app
- icon-192.png, icon-512.png, apple-touch-icon.png   icone (uguali a prima)

0) PRIMA DI TUTTO: salva i progetti
   L'indirizzo dell'app cambia, e ogni indirizzo ha una memoria separata.
   Nella vecchia app: scheda Progetti > "Esporta tutti" e salva il file .json in File.
   Dopo, nella nuova app: Progetti > "Importa".

1) Sostituire i file su GitHub
   Repository zone-dmx > "Add file" > "Upload files" > scegli i 6 file > "Commit changes".

2) Rendere il repository privato
   Settings > General > in fondo "Danger Zone" > "Change visibility" > "Make private".
   Poi Settings > Pages: togli la pubblicazione (GitHub Pages pubblica il sito per tutti,
   anche da un repository privato, quindi non va bene per un'app privata).

3) Mettere l'app online su Cloudflare Pages (gratis)
   dash.cloudflare.com > crea l'account > "Workers & Pages" > "Create" > scheda "Pages"
   > "Connect to Git" > collega GitHub dando accesso SOLO al repository zone-dmx.
   Impostazioni: Framework preset "None", Build command vuoto, Build output directory vuoto (o "/").
   Nome del progetto: uno difficile da indovinare. Indirizzo: https://NOME.pages.dev
   Da ora ogni file che carichi su GitHub va online da solo in un minuto.

4) Chiudere l'accesso: solo tu (Cloudflare Zero Trust, gratis fino a 50 utenti)
   Nel menu di Cloudflare apri "Zero Trust", scegli un nome per il team e il piano Free.
   Access > Applications > Add an application > "Self-hosted":
     - dominio: NOME.pages.dev   (aggiungi anche *.NOME.pages.dev per le versioni di prova)
     - Session duration: 1 month
     - Policy: Action "Allow", regola "Emails" = la tua email
   Settings > Authentication > Login methods: controlla che "One-time PIN" sia attivo.
   Chi apre l'indirizzo vede una pagina che chiede l'email: solo la tua riceve il codice.

5) Installare sull'iPad
   Apri https://NOME.pages.dev in Safari, entra con l'email e il codice,
   poi Condividi > "Aggiungi alla schermata Home". Aprila una volta con la rete.
   Da quel momento funziona anche senza rete, anche se l'accesso scade.

6) Aggiornare in futuro
   Carica il nuovo index.html su GitHub e in sw.js cambia "zone-dmx-v3" in "zone-dmx-v4" (poi v5 ...).
   L'app prende l'aggiornamento alla prima apertura con la rete. Se l'accesso è scaduto,
   apri l'indirizzo in Safari, rientra con il codice, poi riapri l'app.

Privacy
- I progetti restano solo sull'iPad, nella memoria dell'app: non vanno mai su GitHub né su Cloudflare.
- Fai ogni tanto "Esporta tutti" come copia di sicurezza.
